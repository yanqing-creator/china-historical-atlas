# 华夏舆图 · Historical Atlas of China — 设计文档

日期：2026-08-22
状态：已确认

## 1. 目标

制作一张关于中国历史的古风交互式网页地图：
- 多朝代时间轴，展示疆域演变
- 点击城市弹出中英双语详情（历史、地理、气候、景点、美食）+ 旅游攻略
- 可选的 LLM 实时增强攻略（需用户自配 API Key）

## 2. 技术方案

**选型：MapLibre GL JS 矢量瓦片方案**

- Vite + MapLibre GL JS 单页应用，纯前端静态站，可部署到任意静态托管（GitHub Pages / Vercel / Netlify）
- 底图数据用 tippecanoe 在构建时预切为 PMTiles 单文件矢量瓦片（零服务端）
  - 若用户不愿安装 tippecanoe，回退方案：直接加载 GeoJSON 源，功能完全一致
- 动态层（疆域/城市/事件/工程线）用 GeoJSON 直接加载，按朝代过滤显示
- 字体：思源宋体 Noto Serif SC + EB Garamond（CDN 加载，离线回退系统宋体）

## 3. 视觉风格（古风仿古）

- 底图：泛黄宣纸色背景（约 #f3e9d2）+ 细颗粒纹理
- 陆地轮廓、河流、湖泊用墨色/青花蓝细线勾绘
- 疆域边界：半透明朱砂/靛蓝填充 + 墨线描边；并立政权（宋/辽/金/西夏/大理）分色区分
- 符号：都城大号书法字体标注，城市小号标注，事件点印章式图标
- 数据取自 Natural Earth 110m（East Asia 范围：中国 + 蒙古、朝鲜半岛、日本、东南亚、中亚）

## 4. 数据层

### 地理底图
- 陆地轮廓、长江/黄河/珠江等主要河流、湖泊、邻国边界

### 历史图层（自绘简化 GeoJSON，风格化而非精确）
| 图层 | 内容 | 显示时期 |
|------|------|----------|
| 疆域边界 | 5 个时期多边形；宋辽金时期并立政权分色 | 按时期 |
| 长城 | 秦汉长城线 | 秦汉 |
| 长城 | 明长城线 | 元明清 |
| 大运河 | 隋唐大运河 | 隋唐 |
| 大运河 | 京杭大运河 | 元明清 |
| 丝绸之路 | 陆上丝路（长安—河西—西域） | 秦汉、隋唐、宋辽金、元明清 |
| 丝绸之路 | 海上丝路（泉州/广州—南洋） | 宋辽金、元明清 |
| 历史事件点 | 每时期约 5 个，共约 25 个 | 按时期 |

### 时间轴（5 个时期）
秦汉 → 三国两晋南北朝 → 隋唐 → 宋辽金 → 元明清

### 城市（27 个，中英双语全字段）
- 古都类 8：西安·北京·洛阳·南京·开封·杭州·安阳·成都
- 名城类 14：苏州·扬州·绍兴(会稽)·荆州·襄阳·大同·泉州·广州·上海·九江·曲阜·敦煌·喀什
- 风景类 6：桂林·丽江·大理·拉萨·张家界·黄山(徽州)

每个城市字段：
- 今名 + 各朝古名（如 长安/汴京/临安），按当前朝代显示
- 一句话标语（中英）
- 历史、地理、气候、文化景点、美食（中英）
- 3 日旅游攻略（Day 1/2/3，中英）
- 出现朝代列表（如上海仅在元明清显示）

### 历史事件（约 25 个）
双语简介 + 所属时期 + 坐标。

## 5. 界面与交互

### 布局
- 顶部：标题「华夏舆图 · Historical Atlas of China」+ 5 时期时间轴按钮
- 右上角：中/EN 语言切换 + ⚙️ 设置（API Key）
- 左侧：可折叠图例（疆域、都城、城市、事件、长城、运河、丝路）
- 右侧：点击城市/事件 → 滑出详情面板（约占屏 1/3）

### 城市详情弹窗
1. 头部：城市名（今名 + 当前朝代古名）+ 中英标语
2. 标签页：📜 历史 ｜ 🌍 地理 ｜ 🌤 气候 ｜ 🏛 景点 ｜ 🍜 美食 ｜ 🧭 旅游攻略
3. 攻略页：3 日行程；已配置 API Key 时出现「✨ AI 增强」按钮
4. 语言切换作用于全弹窗

### 交互细节
- 切换朝代：图层整体淡入淡出，视野平滑飞至该朝都城
- 城市圆点按朝代出现/消失
- 移动端适配：详情面板改为底部抽屉

## 6. LLM 可选增强

- 设置面板粘贴 OpenAI 兼容 API Key（存 localStorage，仅本机，不上传）
- 「AI 增强」按钮调用 chat completions 接口，提示词模板含城市基础信息与预写攻略，生成个性化增强攻略
- 未配置 Key 时按钮不出现，功能完全降级为预写内容

## 7. 目录结构

```
世界地图/

├─ package.json / vite.config.js
```

## 8. 验收标准

1. `npm run validate` 通过：27 城全部字段中英齐全、事件引用有效
2. 5 个时期切换正确显示对应疆域/城市/工程图层
3. 任意城市弹出 6 标签双语面板，语言切换生效
4. 长城（秦汉/明）、运河（隋唐/京杭）、丝路（陆/海）在正确时期出现
5. 未配 Key 时无 AI 按钮，配置后可用
6. `npm run build` 产物可部署到任意静态托管
